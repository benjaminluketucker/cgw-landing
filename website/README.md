It checks public bytes without sending provider credentials, then rechecks alias ownership. A missing read, changed byte, unknown source or moving deployment refuses with website_live_changed. The worker repeats this check after candidate verification, before the first promotion request. Reconciliation after an uncertain promotion keeps its existing durable behavior.
